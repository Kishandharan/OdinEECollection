## OdinEECollection
An Odin Package Collection of emulators for various Digital Electronics ICs.

### Available Emulators
- 74hc670 Emulator: [README](https://github.com/Kishandharan/OdinEECollection/blob/main/EMU_74xx670/README.md)
### How to use 
Once you have cloned this repo (you can clone it wherever you like), add this flag to your build/run command:
``` 
-collection:importname=repopath
```
Replace `importname` with whatever name you would like to import this collection with in your code, and replace `repopath` with the path of the cloned repo.
